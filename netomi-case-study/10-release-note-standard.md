<p><strong>Goal:</strong> consistent, actionable release notes every week.</p>

<h3>Required fields</h3>
<ul>
  <li>Type + title + summary</li>
  <li>Who is affected + required action</li>
  <li>Limitations + links</li>
</ul>

<h3>Voice and style rules</h3>
<ul>
  <li>User impact first</li>
  <li>Plain language</li>
  <li>No internal jargon</li>
  <li>Explicit pending confirmations</li>
</ul>
